2. 수집하지 않는 정보

  • 이름, 주민등록번호, GPS 좌표
  • 결제 카드 정보 (현재 무통장·수동 발급 중심)
  • 고객 OpenAI API 키 (서버 관리형 키만 사용)

3. 이용 목적

  • 라이선스 확인 및 일·월 사용량 한도 관리
  • AI 이미지 생성 (OpenAI 등)
  • 고객 문의 대응

4. 제3자 제공

이미지 생성을 위해 입력 텍스트·참고 이미지가 OpenAI 등 AI 제공자에 전송됩니다. 그 외 제3자에게 판매하거나 제공하지 않습니다.

5. 보관 기간

  • 라이선스 정보: 구독 만료 후 1년 또는 관련 법령
  • API 요청 로그: 90일
  • 생성 요청 본문·업로드 이미지: 서버에 장기 저장하지 않음
