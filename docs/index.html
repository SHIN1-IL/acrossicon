웹앱 열기 설치 · 사용 방법

세 가지 생성 모드

최소 입력만으로 모드별 전문 프롬프트를 자동 합성합니다.

01

로고

아이콘, 로고+글씨, 워드마크. 형태와 컬러 테마까지 맞춰 후보를 뽑습니다.

02

상품 배너

상품 강조, 한 줄 카피, 포인트 문구로 판매용 비주얼을 만듭니다.

03

홈 / 배너

새로 생성하거나, 무료 라이선스 이미지를 올려 재해석 변환합니다.

사용 방법

링크만 있으면 Chrome 설치 없이 바로 쓸 수 있습니다.

웹에서 바로 사용 acrossicon.onrender.com/app 접속 → 라이선스 키 + API 키 등록
이미지 생성 로고 · 상품 배너 · 홈 히어로를 바로 만들고 다운로드합니다.
(선택) Chrome 확장 개발자용: GitHub에서 빌드 후 dist를 Load unpacked
